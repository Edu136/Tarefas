# 🧠 Projeto de Gerenciamento de Tarefas

Este é um projeto fullstack de gerenciamento de tarefas, com **frontend em React** e **backend em Node.js + MySQL**, criado para fins de aprendizado e prática.

---

## 📁 Estrutura do Projeto
/meu-app 
  ├── backend/ # API REST feita com Node.js + Express + MySQL 
  ├── frontend/ # Interface feita com React + Vite 
  ├── README.md 
  └── .gitignore

---

## 🚀 Tecnologias Utilizadas

### 🖥️ Frontend:
- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [ShadCN/UI](https://ui.shadcn.dev/) (opcional)
- Toasts, Forms, Hooks

### 🌐 Backend:
- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- [MySQL](https://www.mysql.com/)
- [Cors](https://www.npmjs.com/package/cors)
- [Dotenv](https://www.npmjs.com/package/dotenv)

---

### Pré-requisitos:
- Node.js instalado
- MySQL local ou online (ex: AlwaysData)
- Yarn ou npm
